# Retroslop Mall

This game is a retro-styled recreation of the original Roblox Mall tycoon from 2010 by Nightcaller, but with some modern features.

## Original features

These features are the same from the original Roblox Mall:

- Individual stores
  - This is a tycoon game but each tycoon is a different store!
  - The last item to purchase is the item giver, which also puts an open sign on the storefront
    - The item giver shows a UI on-screen when you touch it, you can purchase items from there
  - Players can visit your store
- VIP room
  - Purchase VIP to enter the VIP room and press buttons to get money
- Laser tag arena
  - Join either red or blue team
  - Earn money by tagging players
  - Getting tagged respawns you back at the start of the mall
- When you spawn, you walk to an un-owned store to claim it
- Server time clock
- Players online and how many players were in this server tracker
- Segways (won't be implemented yet, will be in a future update)
- You can mess with other players using items you've purchased, but not too much because the owner doors will reset you

## Features

These are new additions in Retroslop Mall:

- Badges
  - Own a store to earn a basic badge with that store's logo
  - Rebirth a store to earn a golden badge with that store's logo
  - Earn a basic Mall badge when you've opened one of each store in the game
  - Earn a golden Mall badge when you rebirth at least once in all of the stores in the game
- Rebirths
  - After completing a store, you can rebirth after spending a large amount of money to buy it
  - Rebirthing will reset the store and you can earn money faster after each rebirth
  - Each store has their own set of rebirths, it's not a global count
  - Rebirthing will unlock more gear for you and others to purchase in the store
- Rewards
  - Playing the game will give you periodical rewards to redeem
  - There are also daily quests, such as visiting a store or purchasing an item from a complete store
- Easter eggs
  - Where there was formerly a backdoor giver as a hidden button that you can jump to touch, it slips you like a banana peel when you touch it instead
- Map
  - The mall model has been reworked to make the ceilings translucent
  - Clicking on the map button will hide the top roof and show a top 2d orthographic view of each player and the store's logo
- Run button
- HUD with money, owned models, and rebirth count
